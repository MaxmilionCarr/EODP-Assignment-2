This assignment takes datasets taken from 2025's Victorian Integrated Survey of Travel and Activity (VISTA) and applies 
pre-processing, correlation, clustering and learning models to produce conclusions in line with the overarching report.

## Implementation
1. Data was preprocessed, cleaned and encoded ready for further analysis
2. NMI analysis was conducted to determine prominent features for future use in correlation analysis
3. Correlation analysis on prominent features with both the highest NMI and targeted features chosen
4. Clustering was done to determine feature groups amongst individuals
5. Decision Tree analysis and K-nearest neighbour learning models were implemented to predict travel mode

## Installation
1. Clone repository
2. Read requirements - "pip install -r requirements.txt"

## Run
Execute the run.py file - "python run.py all"
